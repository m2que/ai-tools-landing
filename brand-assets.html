Usage Guidance

How the system should stay consistent

This is a practical guide for keeping the new MarketLearn direction consistent across static landing-page assets.

Typography

Direct, academic, modern

Use Inter throughout, with dense weights, compact tracking, and short high-signal headings.

Color Balance

Cool neutrals first

Lead with white and slate surfaces, reserve indigo for anchor actions, and use the wider accent set as controlled support.

Icon Style

Single-outline forms

Keep original icon geometry intact while updating tile shape, color framing, and surrounding panel composition.
